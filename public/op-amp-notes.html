§0 先備觀念

理想 OP 與兩大法寶

Operational amplifier

先看這裡：電路圖符號小字典

基本名詞：後面每個推導都會用到

電壓 V
單位伏特（V）。說「某個點是 2 V」，意思是這個點比接地（0 V）高 2 V。電壓永遠是「兩點之間」的差，只寫一個點時，另一點預設是地。
電流 I
單位安培（A），1 mA = 0.001 A。流過電阻時，電流一定是從電壓高的那端流向電壓低的那端。
接地
定義為 0 V 的點，電路裡所有電壓都以它為基準。電路圖上的接地符號全部是同一個點。
節點
用導線（沒有元件）連在一起的地方。同一個節點上每一點電壓都一樣。

歐姆定律：電阻上的電流怎麼算

電阻兩端的電壓差 = 流過的電流 × 電阻，也就是 V = I·R。反過來寫成求電流：

I = （高端電壓）−（低端電壓）R

電流方向可以先假設：寫式子時可以先隨便決定電流往哪個方向，照「假設的起點電壓 − 終點電壓」去寫。算出來是負的，代表實際方向跟假設相反，式子本身還是對的。正相放大器的 (0 − Vi)/R1 就是這樣寫出來的。

KCL：節點的電流守恆

流進一個節點的電流總和 = 流出這個節點的電流總和。電荷不會在節點憑空消失或堆積。

重疊定理：有好幾個電源時怎麼算

電路裡有兩個以上的電源（例如 V1、V2）時：

  1. 一次只留一個電源，其他的電壓源換成一條導線接地（電壓 = 0，叫做「關掉」或「短路」）。電流源關掉則是拔掉（開路）。
  2. 算出只有這個電源時的輸出。
  3. 每個電源都算一次，最後把所有輸出相加，就是全部電源一起作用時的輸出。

這招只能用在「線性電路」（電阻、電容、在線性區工作的 OP）。反相加法器和減法器都用這招。白板寫的「V1 對 Vo 的貢獻 ⇒ V2 關」就是第 1 步。

輸入阻抗：「從某一點看進去」是什麼意思

在電路的某個接點外加一個測試電壓 V，量流進去的電流 I。V 除以 I 就是從這一點「看進去」的電阻，叫輸入阻抗：Rin = V / I。不管裡面接了多複雜的東西，對外面來說它就跟一顆 Rin 的電阻效果一樣，這就是「等效」。

輸入阻抗越大越好的原因：Rin 越大，同樣的電壓下 I 越小，訊號源被拉走的電流越少，訊號源的電壓就不會被拉低。理想 OP 的輸入腳 Rin = ∞，完全不拉電流。

輸出阻抗：輸出端內部的電阻

任何輸出都可以看成「一個內部電壓源串一顆電阻 Ro」。接上負載後有電流 IL，Ro 上會掉 IL·Ro 的電壓，所以輸出電壓會變低。

另外兩個元件的公式

電容 C
i = C·dV/dt：電容的電流跟「它兩端電壓變化的速度」成正比。電壓變得越快，電流越大；電壓固定不變時，電流 = 0。積分器、微分器用的就是這條。
二極體 D
電流只能往三角形尖端的方向流（順向）。順向時 I = Is(eV/nVT − 1)，電壓多一點點，電流就呈指數增加；反向時電流幾乎是 0。指數放大器用的就是這條。

OP 本身在做什麼

OP 是一個「差動放大器」：差動的意思是它只看兩個輸入端的電壓差（v+ − v−），不管兩端各自是多少，然後把這個差放大 Av 倍。Av 非常大（真實 OP 大約 105，理想 OP 當作 ∞）。

開迴路增益
OP 自己、沒接任何回授時的放大倍數，就是 Av。
閉迴路增益
接上回授電阻之後，整個電路的 Vo/Vi，例如反相放大器的 −R2/R1。後面每一節算的「增益」都是這個。
飽和
OP 的輸出不可能超過電源電壓。輸出被頂在最大值（筆記裡是 ±3 V）時叫飽和，記作 ±Vsat，這時 OP 已經不照 Vo = Av(v+ − v−) 運作。
Vo = Av(v+ − v−)

回授長什麼樣子：從輸出往回找

「回授」就是把輸出接一條線（或經過電阻、電容）繞回輸入端。判斷方法只有一步：用手指從輸出 Vo 沿著線往回走，看最後回到哪一個輸入腳。

負回授為什麼會穩定：沿著電路一步一步推

用上面中間那張負回授圖（+ 端接輸入 Vi，輸出直接接回 − 端，所以 v− 永遠等於 Vo）。OP 的公式是 Vo = Av(v+ − v−)：

  1. 假設 Vo 不小心變大一點 → v− 跟著變大（它就是 Vo）→ (v+ − v−) 變小 → 乘上 Av 後 Vo 變小 → 被拉回來。
  2. 假設 Vo 不小心變小一點 → v− 變小 → (v+ − v−) 變大 → Vo 變大 → 被推回來。
  3. 不管往哪邊偏，都會被修正回來，所以輸出會停在一個固定值。停下來的時候 v+ 和 v− 幾乎相等（下面的虛短路用數字驗證給你看）。

換成正回授（輸出接回 + 端）：Vo 變大一點 → v+ 變大 → (v+ − v−) 變大 → Vo 再變大 → 一路衝到 +Vsat 才停。輸出只會停在 ±Vsat，這時 v+ ≠ v−，所以不能用虛短路。

法寶一：虛斷路（管電流）

理想 OP 兩個輸入腳之間的輸入電阻 Ri = ∞。代入歐姆定律 I = V/Ri = V/∞ = 0，不管電壓多少，電流都是 0，所以沒有任何電流能流進 OP 的兩隻輸入腳：i+ = i− = 0。你筆記寫的「撞牆」就是這個意思。

考試怎麼用：在 − 端那個節點寫 KCL 時，「流進 OP 的電流」直接寫 0。所以流進節點的電流 = 流出去走回授元件的電流（上圖：流過 R1 的 i ＝ 流過 R2 的 i）。

法寶二：虛短路（管電壓）

一句話：有負回授時，OP 會自己調整輸出，讓 + 端和 − 端的電壓一樣：v+ = v−。為什麼？直接用最簡單的電壓隨耦器代數字算給你看。

代數字：真實 OP 的 Av 大約 100000
Vo = Av(v+ − v−)OP 的基本公式
v+ = 2 V，v− = Vo+ 接輸入；− 被回授線接到輸出
Vo = 100000 × (2 − Vo)
Vo = 200000 − 100000Vo
Vo + 100000Vo = 200000移項
100001Vo = 200000
Vo = 200000100001 ≈ 1.99998 V
v+ − v− = 2 − 1.99998 = 0.00002 V ≈ 0

兩端只差 0.00002 V，小到可以直接當成 0。Av 越大差距越小；理想 OP 的 Av = ∞，差距就剛好是 0，這就是 v+ = v−。

它是怎麼「自己調整」的

假設輸出一開始太小，Vo = 1.9 V：兩端差 2 − 1.9 = 0.1 V，乘上 100000 = 10000 V。輸出不可能真的到 10000 V，這代表 OP 會把輸出往上推。

假設輸出太大，Vo = 2.1 V：兩端差 2 − 2.1 = −0.1 V，OP 拼命把輸出往下拉。

只有 Vo 幾乎剛好等於 2 V 時才不推不拉，所以輸出會停在那裡。這就是負回授「偏多少拉回多少」。

為什麼叫「虛」短路：兩端電壓一樣，就像用導線短路起來；但它們之間其實沒有接線，也沒有電流流過（虛斷路），所以是「虛」的。圖上都用綠色虛線表示。如果 + 端接地，− 端也會是 0 V，這叫虛接地。

虛斷路：管「電流」輸入腳不吃電流，i⁺ = i⁻ = 0。永遠成立（因為 Ri = ∞）
虛短路：管「電壓」兩個輸入腳電壓一樣，v⁺ = v⁻。只有負回授時成立

所有 OP 題目的解題 SOP

  1. 先確認有負回授 → 才可以用虛短路 v+ = v−。
  2. 先求 v+（通常是接地 = 0，或直接接輸入，或經過分壓），得到 v−。
  3. 在 − 端節點寫 KCL：流進來的電流 = 流出去的電流。因為虛斷路，電流不會流進 OP，全部走回授元件。
  4. 解出 Vo。有多個電源時，用重疊定理（一次只留一個電源，其他電壓源短路接地）。
筆記勘誤（p.34）
  • 「理想 OP 負回授 Vo still = v+ − v−」漏了 Av：應寫 Vo = Av(v+ − v−)。負回授時這條式子仍然成立，只是 v+ − v− 被壓到趨近 0。
  • 「負回授限制了 Av」比較精確的說法：OP 自己的開迴路增益 Av 還是 ∞，負回授限制的是整個電路的閉迴路增益（變成由外接電阻決定，例如 −R2/R1）。
  • 「理想時 v+ − v− = 0」要加條件：有負回授且沒飽和。像 p.34 那張圖（沒有回授、+ 端接地）就不能用虛短路，輸出會直接飽和。
  • 「Av = ∞（開路增益）」課本用語通常是「開迴路增益」（open-loop gain）。
  • 筆記只寫了虛短路，漏了虛斷路 i = 0 和 Ro = 0，後面每個推導都會用到，建議補上。
  • 飽和電壓：實際 OP 通常飽和在比電源低一點的位置（例如 ±3 V 電源可能只到 ±2.x V），除非是 rail-to-rail 的 OP。小考照老師的「飽和在 ±3 V」寫即可。

§1 · 老師畫兩顆星

反相放大器

Inverting amplifier
作用
用途：感測器、麥克風的訊號常常只有幾 mV，太小，後面的電路讀不到，要先放大。反相放大器把它放大 R2/R1 倍，但正負會顛倒（Vi 正 → Vo 負）。
原理
虛接地 ＋ 虛斷路：R1 的電流進不了 OP，只能全部流過 R2。

電路怎麼 work

  1. + 端接地 → v+ = 0。
  2. 有負回授（R2 把輸出接回 − 端）→ 虛短路：v− = v+ = 0（虛接地）。
  3. R1 左邊是 Vi、右邊是 0 V → i1 = (Vi − 0)/R1。
  4. 虛斷路：i1 進不了 OP，全部流過 R2 → i2 = i1。
  5. R2 左邊 0 V、右邊 Vo → i2 = (0 − Vo)/R2。電流從 0 V 流向 Vo，所以 Vo 一定比 0 低 → 負號的由來。
推導
Vi − 0R1 = 0 − VoR2i₁ = i₂
ViR1 = −VoR2
Vo = −R2R1·Vi兩邊同乘 −R₂
A = VoVi = −R2R1

例：R1 = 1 kΩ、R2 = 10 kΩ → A = −10 kΩ / 1 kΩ = −10。Vi = 0.1 V → Vo = −10 × 0.1 V = −1 V。
輸入阻抗 = R1：− 端是 0 V，從 Vi 看進去只看到 R1 接到「地」。這是它跟正相放大器最大的差別。

筆記勘誤（p.35）
  • 推導第一行右邊那項，筆記看起來寫成 (0 − Vi)/R2。R2 右邊接的是輸出，應該是 (0 − Vo)/R2。如果你原本寫的是 Vo 只是字跡像 Vi，就沒問題。

正相放大器

Non-inverting amplifier
作用
用途：一樣是把小訊號放大，但輸出不會正負顛倒；而且它完全不從訊號源拉電流，適合接那種一被拉電流電壓就會掉的訊號源。放大倍數 1 + R2/R1。
原理
訊號直接進 + 端，虛短路把 − 端也拉到 Vi；R1、R2 其實是一個分壓器。

電路怎麼 work

  1. Vi 直接接 + 端 → v+ = Vi。
  2. 虛短路 → v− = Vi。
  3. R1 上端是 Vi、下端接地 0 V，電流照圖上紅色箭頭從節點流到地：i = (Vi − 0)/R1。
  4. 虛斷路：OP 不吃電流，所以流過 R1 的 i 一定是從 R2 流過來的（圖上兩個紅色箭頭是同一個電流）。R2 左端 Vo、右端 Vi：i = (Vo − Vi)/R2。
推導（照圖上箭頭方向寫）
Vi − 0R1 = Vo − ViR2流過 R₁ 的 i ＝ 流過 R₂ 的 i
Vi·R2 = (Vo − Vi)·R1兩邊同乘 R₁R₂
ViR2 = VoR1 − ViR1
VoR1 = ViR1 + ViR2移項
VoVi = R1 + R2R1
A = 1 + R2R1

跟你筆記寫法的關係：筆記寫的是 (0 − Vi)/R1 = (Vi − Vo)/R2，等於把電流方向假設成跟箭頭相反（從地往上流）。兩邊各乘 −1 就是上面第一行，所以兩種寫法都對、結果一樣。
另一種想法（分壓）：OP 不吃電流，所以 R2、R1 是串聯分壓：v− = Vo·R1/(R1 + R2)，再令它等於 Vi，一樣得到 Vo/Vi = (R1 + R2)/R1。
例：R1 = 1 kΩ、R2 = 9 kΩ → A = 1 + 9 kΩ / 1 kΩ = 1 + 9 = 10。
白板寫法：老師把回授電阻叫 Rf：Vo = (1 + Rf/R1)Vi，Rf 跟這裡的 R2 是同一顆。這個電路也是下一節減法器裡「V2 那一半」的基礎。

筆記勘誤（p.35 下半）
  • 電路圖上接地的電阻標成 R3，但公式 A = 1 + R2/R1 用的是 R1。請統一改成 R1，不然考試時會對不起來。
  • 推導只寫到 (0 − Vi)/R1 = (Vi − Vo)/R2，這行本身是對的（電流方向假設成往上），後面的移項請照上面補齊。

電壓隨耦器

Voltage buffer / voltage follower
作用
用途：訊號源推不動後面的負載時用，例如一個訊號要同時接很多電路，一接上電壓就被拉低。把它加在中間，Vo = Vi 不放大，但負載要的電流改由 OP 供應，訊號源不用出電流，電壓就不會掉。
原理
輸出整條接回 − 端（100% 負回授），虛短路直接讓 Vo = Vi。

電路怎麼 work

  1. 輸出用導線直接接回 − 端 → v− = Vo。
  2. 虛斷路：+ 端不吃電流 → Rs 上電流 I = 0 → 壓降 I·Rs = 0·Rs = 0（筆記說的「不用付過路費」）→ v+ = Vi。
  3. 虛短路：v− = v+ → Vo = Vi。
  4. Ro = 0：OP 輸出像理想電壓源，接上 RL 後 Vo 還是 Vi（所以「V 不受 RL 影響」）。
推導
v+ = Vi − I·Rs = Vi − 0·Rs = Vi
Vo = v− = v+ = Vi
Av = VoVi = 1也可看成正相放大器 R₂ = 0、R₁ = ∞：1 + 0/∞ = 1

為什麼需要它：沒加 buffer vs 加了 buffer

「V 不受 RL 影響」是 buffer 的好處。老師為了說明這個好處，先畫了沒有 buffer 的情況給你看（下面第一張，筆記裡叫「左圖」）：這時候 Vo 會被 RL 拉低。加上 buffer（第二張，「右圖」）之後就不會了。所以下面的「分壓」講的是左圖、沒加 buffer 的壞處，不是 buffer 本身。

左圖（沒加 buffer）① 還沒接 RL
沒有電流 ⇒ Rs 沒有壓降 ⇒ Vo = Vi
左圖（沒加 buffer）② 接上 RL：分壓
Vo = Vi·RLRs + RL < Vi ⇒ Vo ↓這就是負載效應
例：Rs = RL = 1 kΩ ⇒ Vo = Vi × 1 kΩ1 kΩ + 1 kΩ = Vi × 12
右圖（加了 buffer）③ 接上 RL
i = 0 ⇒ v+ = Vi ⇒ 虛短路 v− = Vi ⇒ Vo = ViRL 沒出現在式子裡
同樣 Rs = RL = 1 kΩ：Vo = Vi（左圖只剩 Vi × 1/2）

筆記寫的「fan out ↑」是什麼意思：一個訊號源要同時推 100 個電路，這 100 個輸入電阻是並聯，總負載變得很小。假設每個電路輸入電阻 10 kΩ、Rs = 1 kΩ。
沒加 buffer（像左圖）：
RL = 10 kΩ / 100 = 100 Ω
Vo = Vi × 100 Ω / (1000 Ω + 100 Ω) = Vi × 100/1100 ≈ 0.091 Vi，只剩不到一成，後面的電路都收不到正確的電壓。
加了 buffer（像右圖）：訊號源只看到 OP 的 + 端（Ri = ∞，不用出電流，Vi 完整保留），100 個電路改由 OP 輸出（Ro = 0）來推，每個都拿到 Vi。

筆記勘誤（p.37）
  • 筆記寫「過路費 I·Rs = 0·Rs，Rs = 0」。Rs 本身不是 0，是 Rs 上的壓降為 0：VRs = I·Rs = 0·Rs = 0。
  • 對照新的白板照片：老師寫的是「I·Rs = 0·Rs」，下一行「= 0」，再下面那個「Rs」其實是電阻的標籤。抄的時候兩個黏在一起，就變成「Rs = 0」了。

反相加法器

Inverting summing amplifier
作用
用途：要把好幾個訊號合成一個時用，例如混音器把幾支麥克風的聲音混在一起。每個輸入的比重（Rf/R1、Rf/R2）可以用電阻分別調，輸出是相加後再加負號。
原理
− 端是虛接地 0 V，所以每個輸入的電流各算各的、互不干擾，在節點匯合後全部流過 Rf。

電路怎麼 work

  1. + 端接地 → 虛短路 → − 端 = 0 V。
  2. R1 兩端：V1 和 0 V → i1 = V1/R1；R2 兩端：V2 和 0 V → i2 = V2/R2。因為節點固定在 0 V，V2 改變不會影響 i1。
  3. 虛斷路 → i1 + i2 全部流過 Rf。
  4. Rf 左邊 0 V、右邊 Vo → Vo = 0 − (i1 + i2)·Rf。
方法一：KCL
V1 − 0R1 + V2 − 0R2 = 0 − VoRf
V1R1 + V2R2 = −VoRf
Vo = −Rf(V1R1 + V2R2)兩邊同乘 −Rf
Vo = −(RfR1V1 + RfR2V2)
方法二：重疊定理（筆記的方法）
只留 V₁（V₂ 關掉＝短路接地）：
Vo1 = −RfR1V1
只留 V₂（V₁ 短路接地）：
Vo2 = −RfR2V2
Vo = Vo1 + Vo2
代數字：R1 = R2 = Rf = 10 kΩ，V1 = 1 V、V2 = 0.5 V
i1 = 1 V / 10000 Ω = 0.1 mA，i2 = 0.5 V / 10000 Ω = 0.05 mA
流過 Rf：i1 + i2 = 0.1 mA + 0.05 mA = 0.15 mA
Vo = 0 − 0.15 mA × 10 kΩ = −1.5 V = −(1 V + 0.5 V) ✓

為什麼「V₂ 關掉」不會影響 V₁ 的那一半：V₂ 短路接地後，R2 一端是 0 V（地）、另一端也是 0 V（虛接地），兩端沒電壓差 → 沒電流 → 就像不存在，電路變回單純的反相放大器。
補充：重疊定理裡，電壓源關掉 = 短路，電流源關掉 = 開路。
白板寫法：Vo = V1·(−Rf/R1) + V2·(−Rf/R2) = −(V1·係 + V2·係)，「係」就是係數 Rf/R1、Rf/R2。

筆記勘誤（p.38）
  • 對照白板「△ 加法器」那張：匯合線和 − 端之間寫的是「0V」（標示虛接地），不是電阻。筆記很可能把這個手寫的「0V」抄成了一顆電阻。
  • 電路圖上 V1-R1、V2-R2 匯合之後，又多串了一顆電阻才接到 − 端。標準加法器沒有這顆，R1、R2 要直接接到 − 端節點。多串一顆的話，匯合點就不是 0 V，V1、V2 的電流會互相影響，Vo = −(Rf/R1·V1 + Rf/R2·V2) 就不成立了。
§5

減法器（正反相加法器）

Difference amplifier / subtractor
作用
用途：要量「兩點之間的電壓差」時用，例如應變規電橋（下面有例子）。兩條線上相同的部分（共同的電壓、共同的雜訊）會被消掉，只放大兩者的差：Vo = k(V2 − V1)，k = Rf/R1（條件是 Rf/R1 = R3/R2）。
原理
V1 接在 − 端，對輸出的貢獻是負的（反相放大）；V2 接在 + 端，貢獻是正的（正相放大）。電阻選得讓兩個貢獻的大小剛好一樣，只差正負號，相加後就變成 k·V2 − k·V1。

什麼時候需要它：量「兩點之間的電壓差」

很多感測器的訊號不是「某一點對地的電壓」，而是「兩條線之間的電壓差」，而且這兩條線本身都帶著一個很大的共同電壓。應變規（strain gauge）就是典型例子：應變規是一種受力變形時電阻會改變的元件，通常和三顆固定電阻接成惠斯登電橋（四顆電阻接成一個菱形，從上下兩端加電源，從左右兩個點取出 V1、V2）。沒受力時四顆電阻平衡，V1 = V2；受力後應變規電阻變了，V2 稍微偏離 V1。

例：應變規電橋，電源 5 V
沒受力時：電橋兩個輸出 V1 = 2.500 V、V2 = 2.500 V
受力後：V1 = 2.500 V、V2 = 2.505 V真正的訊號只有 2.505 − 2.500 = 0.005 V
做法一：只把 V₂ 放大 100 倍（正相放大器）
Vo = 100 × 2.505 V = 250.5 V遠超過 ±3 V → 直接飽和，量不到東西
做法二：減法器，k = Rf/R1 = 100
Vo = 100 × (2.505 − 2.500) = 100 × 0.005 = 0.5 V2.5 V 的共同部分被消掉，只放大 0.005 V
受力越大 → V₂ − V₁ 越大 → Vo 越大，量出來的就是受力

同樣的道理：兩條訊號線上如果混進一樣的雜訊（例如兩條線都多了 0.1 V），V2 − V1 時雜訊也會被減掉。

代數字看「一正一負」怎麼變成減法

取白板條件 Rf = R1、R2 = R3；V1 = 2 V、V2 = 3 V
V₁ 的貢獻（走 − 端，反相放大 −Rf/R1 = −1 倍）：Vo1 = −1 × 2 V = −2 V
V₂ 的貢獻（走 + 端）：先分壓 3 V × 12 = 1.5 V，再正相放大 (1 + 1) = 2 倍 ⇒ Vo2 = 2 × 1.5 V = 3 V
兩個貢獻相加：Vo = −2 V + 3 V = 1 V
驗算：V2 − V1 = 3 V − 2 V = 1 V ✓

為什麼 + 端要先分壓：正相放大器的倍數是 1 + Rf/R1，一定比反相那邊的 Rf/R1 多 1（這裡是 2 倍對 1 倍）。為了讓兩邊大小一樣，V2 要先用 R2、R3 砍成一半，2 × 1/2 = 1，才會跟 V1 那邊的 1 倍一樣大。

電路怎麼 work

  1. 只留 V1（V2 短路接地）：+ 端經 R2、R3 接地 → v+ = 0 → 變成反相放大器 → Vo1 = −(Rf/R1)V1。
  2. 只留 V2（V1 短路接地）：虛斷路，+ 端不吃電流，所以 R2、R3 是單純分壓 → v+ = V2·R3/(R2 + R3)。
  3. 這時 R1 從 − 端接地、Rf 接回輸出 → 變成正相放大器，把 v+ 放大 (1 + Rf/R1) 倍。
  4. 兩者相加：Vo = Vo1 + Vo2。
推導
Vo = −RfR1V1 + (1 + RfR1)·R3R2 + R3·V2
白板條件：RfR1 = 1（Rf = R1），R3R2 + R3 = 12（R2 = R3）
Vo = −1·V1 + (1 + 1)·12·V2
Vo = −V1 + 2·12·V2 = −V1 + V2
Vo = V2 − V1
一般條件（考試可能問）
設 RfR1 = R3R2 = k，則 R3 = kR2
V₂ 的係數 = (1 + k)·kR2R2 + kR2 = (1 + k)·k1 + k = k
Vo = k(V2 − V1) = RfR1(V2 − V1)
筆記勘誤（p.39）＋白板「V₂ − V₁ ⇒ 怎麼做？」
  • 你筆記的圖是 V2 直接接 + 端（沒有 R2、R3）。這樣算出來是 Vo = −(Rf/R1)V1 + (1 + Rf/R1)V2，就是白板右邊寫的那條。取 Rf = R1：Vo = −V1 + (1 + 1)V2 = −V1 + 2V2，不是 V2 − V1。
  • 白板問號的答案：在 + 端加 R2、R3 分壓，把 V2 先砍一半（× 1/2），再被放大 2 倍，係數就回到 1，得到 V2 − V1。
  • 筆記圖上 − 端那條輸入沒有標 V1 和 R1、回授電阻沒標 Rf，建議補上。
§6 · 白板 △

負阻抗轉換器／定電流源

Negative impedance converter · Howland current source
作用
用途：需要固定電流、而負載電阻會變的場合。例如給溫度感測器（電阻會隨溫度變）固定電流 I，量它兩端電壓 V，就能用 R = V/I 算出電阻、換算成溫度；或給 LED 固定電流讓亮度穩定。這個電路的電流固定 = Vi/R，RL 怎麼變都一樣。它做得到，是因為藍色虛線框那一塊等效成 −R，把輸入的 R 抵銷掉（r1 = r2 時）。
原理
r1、r2 分壓決定 − 端電壓，虛短路把 + 端也鎖在同一個電壓，再對 + 端寫 KCL。

電路怎麼 work

  1. 這個電路同時有負回授（經 r2 回 − 端）和正回授（經 R 回 + 端）。「回授比例」指輸出電壓 Vo 經過電阻分壓後，有幾成回到輸入腳。負回授：Vo 經 r2、r1 分壓回到 − 腳，比例 = r1/(r1 + r2)，r1 = r2 時 = 1/2。正回授：Vo 經回授 R 回到 + 腳，+ 腳到地之間還有 RL 和輸入 R 並聯（記作 R∥RL = R·RL/(R + RL)，一定比 R 小），比例 = (R∥RL)/(R + R∥RL)，一定小於 1/2。負回授比例比較大，整體還是負回授，所以虛短路仍可用。
  2. 令 r1 = r2 = r。虛斷路 → r1、r2 串聯分壓 → − 端電壓 Vx = Vo/2。
  3. 虛短路 → + 端（也就是 RL 上端）也是 Vx = Vo/2，換句話說 Vo = 2Vx。
  4. ① 流過輸入 R：(Vi − Vx)/R；② 流過回授 R（從 + 端流向 Vo）：(Vx − Vo)/R。
  5. + 端 KCL（OP 不吃電流）：流進 = ①，流出 = IL + ② → IL = ① − ②。
推導：IL 與 RL 無關
Vx = Vo·r1r1 + r2 = Vo·rr + r = Vo2
① = Vi − VxR = Vi − Vo/2R = 2Vi − Vo2R分子分母同乘 2
② = Vx − VoR = Vo/2 − VoR = −Vo/2R = −Vo2R
IL = ① − ② = 2Vi − Vo2R − (−Vo2R) = 2Vi − Vo + Vo2R = 2Vi2R
IL = ViR式子裡沒有 RL → 與 RL 無關
推導：看進去是 −R（白板紅字）
在 + 端把 RL 和輸入 R 剪開，只看藍色虛線框裡那一塊（OP、r1、r2、回授 R），外加測試電壓 Vx，流進去的電流就是 ②：
Ri = Vx② = Vo/2−Vo/(2R) = Vo2·2R−Vo
Ri = −R電壓為正，電流卻是「流出來」的 → 負電阻
一般式（r₁ ≠ r₂）：Vo = Vx(1 + r2r1) ⇒ Ri = −R·r1r2
白板例子：7 kΩ → −1 kΩ（r₁、r₂ 的值是我推的）
R = 7 kΩ，要 Ri = −1 kΩ
−7 kΩ·r1r2 = −1 kΩ ⇒ r1r2 = 1 kΩ7 kΩ = 17
接法一：r1 = 1 kΩ、r2 = 7 kΩ
驗算：Vo = Vx(1 + 7 kΩ1 kΩ) = Vx(1 + 7) = 8Vx
② = Vx − 8Vx7 kΩ = −7Vx7 kΩ = −Vx1 kΩ
Ri = Vx② = Vx ÷ −Vx1 kΩ = −1 kΩ ✓
接法二（如果白板 r₂ 上方的「1k」是 r₂）：r2 = 1 kΩ ⇒ r1 = 1 kΩ7 ≈ 142.9 Ω

Norton 等效：為什麼電流固定

Norton 等效是什麼：「電壓源 V 串一顆電阻 R」可以換成「電流源 V/R 並聯同一顆 R」。兩種畫法對外面接的任何負載，給出的電壓、電流都完全一樣，只是換個角度看。電流源的符號是圓圈裡一個箭頭，表示它固定送出這麼多電流。

把左邊的 Vi 串 R 換成 Norton 形式，再把藍色虛線框換成一顆 −R，整個電路就變成下面這樣（全部並聯在 + 端那個節點和地之間）：

1Req = 1R + 1−R = 0 ⇒ Req = ∞（開路）白板寫法：R·(−R)/(R + (−R)) = −R²/0 → ∞
電流源 Vi/R 唯一的出路就是 RL ⇒ IL = Vi/R（固定）

實際限制：Vx = IL·RL，而 Vo = 2Vx = 2·IL·RL。Vo 不能超過飽和電壓，所以 RL 不能無限大：2·(Vi/R)·RL ≤ Vsat → RL ≤ Vsat·R/(2Vi)。
例：Vsat = 3 V、Vi = 1 V、R = 1 kΩ → IL = 1 V / 1 kΩ = 1 mA；RL ≤ 3 × 1000 / (2 × 1) = 1500 Ω。

要注意的地方
  • 白板標題「電阻 7k → −1k」：數字就是 7k 和 −1k。上面的推導是 r1 = r2 的特例（R → −R）；7k 變 −1k 要用「一般式」，r1/r2 = 1/7（見上面的例子）。白板上 r2 正上方的「1k」是不是在標 r2，我不確定，所以兩種接法都列了。
  • R ∥ (−R) 的分母是 0，嚴格來說不是「除出 ∞」，用電導相加 1/R + 1/(−R) = 0 → 開路，寫起來比較不會被扣分。
§7 · 白板 △

積分器

Integrator
作用
用途：需要把訊號「累積起來」時用，例如把速度訊號累積成位移；也用來把方波變成三角波。輸出 = −(1/RC) × 輸入對時間的積分。
原理
R 把電壓變成電流 Vi/R，這個電流全部拿去給 C 充電；電容電壓 = 電流的累積。

電路怎麼 work

  1. + 端接地 → 虛短路 → v− = 0。
  2. R 兩端：Vi 和 0 V → Ic(t) = (Vi − 0)/R（白板藍字）。
  3. 虛斷路 → Ic 全部流進電容 C 充電。
  4. 電容公式 dVc/dt = i(t)/C，兩邊積分 → Vc(t) = (1/C)∫Ic(t)dt。
  5. 電容左邊 0 V、右邊 Vo：Vc = 0 − Vo → Vo = 0 − Vc(t)。
推導
Vo = 0 − Vc(t)
= −∫Ic(t)Cdt
= −1C∫Ic(t)dtC 是常數，提出來
= −1C∫ViRdt代入 Ic = Vi/R
Vo = −1RC∫Vi dt

例：Vi = 1 V（常數）、R = 10 kΩ、C = 1 μF → RC = 10 × 10³ Ω × 1 × 10⁻⁶ F = 10⁻² s = 0.01 s。Vo = −(1/0.01)·1·t = −100t（V），假設 t = 0 時電容沒有電、Vo = 0。t = 30 ms 時 Vo = −100 × 0.03 = −3 V，已經飽和。
實際電路：C 旁邊通常會並一顆大電阻，否則輸入一點點直流偏移也會被一直積分，最後飽和。

抄寫注意
  • 白板最後一行「= 1/C ∫ Ic(t) dt」照片裡負號不太明顯，抄的時候記得是 −(1/C)∫Ic(t)dt，負號來自 Vo = 0 − Vc。
§8 · 白板

微分器

Differentiator
作用
用途：需要知道訊號「變化得多快」時用，例如把位移訊號變成速度、抓出訊號突然跳變的瞬間；也能把三角波變成方波。輸出 = −RC × 輸入的變化率，輸入不變時輸出 0。
原理
電容只在電壓變化時有電流（i = C·dV/dt）；這個電流全部流過 R，在 R 上產生電壓。

電路怎麼 work

  1. 虛短路 → v− = 0。
  2. 電容兩端：左邊 Vi、右邊 0 V → Vc(t) = Vi − 0 = Vi。
  3. 電容公式 dVc/dt = ic(t)/C → ic(t) = C·dVi/dt。
  4. 虛斷路 → ic 全部流過 R。
  5. R 左邊 0 V、右邊 Vo → Vo = 0 − ic(t)·R（白板黑字）。
推導（白板寫到 Vo = 0 − ic(t)·R，這裡補完）
dVc(t)dt = ic(t)C ⇒ ic(t) = CdVidtVc = Vi
Vo = 0 − ic(t)·R = −R·CdVidt
Vo = −RCdVidt

例：Vi 以 1 V/ms = 1000 V/s 上升、R = 1 kΩ、C = 1 μF → RC = 1 × 10³ Ω × 1 × 10⁻⁶ F = 10⁻³ s。Vo = −10⁻³ s × 1000 V/s = −1 V。
實際電路：雜訊變化很快（dV/dt 大），微分器會把雜訊放大，所以實際上會在 C 前面串一顆小電阻。
口訣：積分器「R 在前、C 在回授」；微分器「C 在前、R 在回授」。

§9 · 白板「7 指數放大」

指數放大器

Exponential (anti-log) amplifier
作用
用途：用電路做數學運算。它和對數放大器（輸出 ∝ ln Vi）搭配：先取對數把乘法變成加法，用加法器相加，再用指數放大器還原，就能用電路算乘法、除法。輸出 ∝ eVi/nVT。
符號
Is：二極體的逆向飽和電流，是元件本身的常數，非常小（大約 10−14 到 10−9 A）。n：理想因子，介於 1 到 2 的常數。VT：熱電壓 = kT/q，室溫約 26 mV。順偏：陽極電壓比陰極高，二極體導通；逆偏：反過來，幾乎不導通。
原理
二極體的電流跟電壓是指數關係；虛接地讓二極體電壓剛好 = Vi，電流再經 R 變回電壓。

電路怎麼 work

  1. 虛短路 → v− = 0（白板上 − 端旁邊寫的「0V」）。
  2. 二極體兩端電壓 VD = Vi − 0 = Vi。
  3. 二極體方程式 ID = Is(eVD/nVT − 1)。順偏時 e 的那項遠大於 1，「−1」可以忽略。
  4. 虛斷路 → ID 全部流過 R。
  5. R 左邊 0 V、右邊 Vo → Vo = 0 − ID·R。
推導
ID = Is(e(Vi − 0)/nVT − 1) ≈ Is·eVi/nVT忽略 −1
Vo = 0 − ID·R
Vo = −Is·R·eVi/nVT−IsR 是係數，nVT 是常數
筆記勘誤／補充
  • 這個公式只在 Vi > 0 且 Vi ≫ nVT（二極體順偏）時成立。室溫 VT = kT/q ≈ 26 mV。Vi < 0 時二極體逆偏，ID ≈ −Is（非常小），Vo ≈ +IsR ≈ 0。
  • 白板把 nVT 標成「常數」：只在溫度固定時成立。VT = kT/q 和 Is 都會隨溫度改變，所以實際的指數放大器對溫度很敏感。
  • 白板第一條式子寫 Vi − 0 在指數上，意思是 VD = Vi − v− = Vi − 0，沒有寫錯。
