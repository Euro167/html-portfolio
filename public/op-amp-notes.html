§0 先備觀念

理想 OP 與兩大法寶

Operational amplifier

先看這裡：電路圖符號小字典

機械系翻譯：把電路想成水管
電子學水管系統
電壓 V水壓（壓力差才會推水流動）
電流 I水的流量
電阻 R細水管／閥門：越細越難流，V = I·R 就像「壓降 = 流量 × 阻力」
接地 0 V大氣壓／海平面：大家量壓力的基準
電容 C水箱：水位就是電壓，進水流量就是電流，所以水位變化率 = 流量 / 截面積（dV/dt = i/C）
OP一個超靈敏的自動閥門：只看兩根輸入管的壓力差，差一點點就把輸出開到最大

OP 本身在做什麼

OP 本身就是一個「增益超大的差動放大器」：它只看兩個輸入端的電壓差，然後放大 Av 倍。

Vo = Av(v+ − v−)

回授長什麼樣子：從輸出往回找

「回授」就是把輸出接一條線（或經過電阻、電容）繞回輸入端。判斷方法只有一步：用手指從輸出 Vo 沿著線往回走，看最後回到哪一個輸入腳。

生活類比

負回授＝冷氣恆溫／汽車定速巡航：太熱就開大、太冷就關小，「偏多少就往反方向拉回多少」，所以會穩定在目標值。

正回授＝麥克風對著喇叭：聲音被放大又收進麥克風再放大，「偏一點就推更遠」，最後變成刺耳的嘯叫（＝飽和）。

如果你修過自動控制：負回授就是「誤差 = 目標 − 實際」接回控制器。OP 的增益超大，所以穩態誤差幾乎是 0，這個「誤差 ≈ 0」就是下面的虛短路。

法寶一：虛斷路（管電流）

理想 OP 的輸入電阻 Ri = ∞。電阻無限大＝管子完全堵死，所以沒有任何電流能流進 OP 的兩隻輸入腳：i+ = i− = 0。你筆記寫的「撞牆」就是這個意思。

考試怎麼用：在 − 端那個節點寫 KCL 時，「流進 OP 的電流」直接寫 0。所以流進節點的電流 = 流出去走回授元件的電流（上圖：流過 R1 的 i ＝ 流過 R2 的 i）。

法寶二：虛短路（管電壓）

一句話：有負回授時，OP 會自己調整輸出，讓 + 端和 − 端的電壓一樣：v+ = v−。為什麼？直接用最簡單的電壓隨耦器代數字算給你看。

代數字：真實 OP 的 Av 大約 100000
Vo = Av(v+ − v−)OP 的基本公式
v+ = 2 V，v− = Vo+ 接輸入；− 被回授線接到輸出
Vo = 100000 × (2 − Vo)
Vo = 200000 − 100000Vo
Vo + 100000Vo = 200000移項
100001Vo = 200000
Vo = 200000100001 ≈ 1.99998 V
v+ − v− = 2 − 1.99998 = 0.00002 V ≈ 0

兩端只差 0.00002 V，小到可以直接當成 0。Av 越大差距越小；理想 OP 的 Av = ∞，差距就剛好是 0，這就是 v+ = v−。

它是怎麼「自己調整」的

假設輸出一開始太小，Vo = 1.9 V：兩端差 2 − 1.9 = 0.1 V，乘上 100000 = 10000 V，OP 拼命把輸出往上推。

假設輸出太大，Vo = 2.1 V：兩端差 2 − 2.1 = −0.1 V，OP 拼命把輸出往下拉。

只有 Vo 幾乎剛好等於 2 V 時才不推不拉，所以輸出會停在那裡。這就是負回授「偏多少拉回多少」。

為什麼叫「虛」短路：兩端電壓一樣，就像用導線短路起來；但它們之間其實沒有接線，也沒有電流流過（虛斷路），所以是「虛」的。圖上都用綠色虛線表示。如果 + 端接地，− 端也會是 0 V，這叫虛接地。

虛斷路：管「電流」輸入腳不吃電流，i⁺ = i⁻ = 0。永遠成立（因為 Ri = ∞）
虛短路：管「電壓」兩個輸入腳電壓一樣，v⁺ = v⁻。只有負回授時成立

所有 OP 題目的解題 SOP

  1. 先確認有負回授 → 才可以用虛短路 v+ = v−。
  2. 先求 v+（通常是接地 = 0，或直接接輸入，或經過分壓），得到 v−。
  3. 在 − 端節點寫 KCL：流進來的電流 = 流出去的電流。因為虛斷路，電流不會流進 OP，全部走回授元件。
  4. 解出 Vo。有多個電源時，用重疊定理（一次只留一個電源，其他電壓源短路接地）。
筆記勘誤（p.34）
  • 「理想 OP 負回授 Vo still = v+ − v−」漏了 Av：應寫 Vo = Av(v+ − v−)。負回授時這條式子仍然成立，只是 v+ − v− 被壓到趨近 0。
  • 「負回授限制了 Av」比較精確的說法：OP 自己的開迴路增益 Av 還是 ∞，負回授限制的是整個電路的閉迴路增益（變成由外接電阻決定，例如 −R2/R1）。
  • 「理想時 v+ − v− = 0」要加條件：有負回授且沒飽和。像 p.34 那張圖（沒有回授、+ 端接地）就不能用虛短路，輸出會直接飽和。
  • 「Av = ∞（開路增益）」課本用語通常是「開迴路增益」（open-loop gain）。
  • 筆記只寫了虛短路，漏了虛斷路 i = 0 和 Ro = 0，後面每個推導都會用到，建議補上。
  • 飽和電壓：實際 OP 通常飽和在比電源低一點的位置（例如 ±3 V 電源可能只到 ±2.x V），除非是 rail-to-rail 的 OP。小考照老師的「飽和在 ±3 V」寫即可。

§1 · 老師畫兩顆星

反相放大器

Inverting amplifier
作用
放大小訊號，輸出和輸入反相（差 180°）。增益只由兩顆電阻決定。
原理
虛接地 ＋ 虛斷路：R1 的電流進不了 OP，只能全部流過 R2。

電路怎麼 work

  1. + 端接地 → v+ = 0。
  2. 有負回授（R2 把輸出接回 − 端）→ 虛短路：v− = v+ = 0（虛接地）。
  3. R1 左邊是 Vi、右邊是 0 V → i1 = (Vi − 0)/R1。
  4. 虛斷路：i1 進不了 OP，全部流過 R2 → i2 = i1。
  5. R2 左邊 0 V、右邊 Vo → i2 = (0 − Vo)/R2。電流從 0 V 流向 Vo，所以 Vo 一定比 0 低 → 負號的由來。
推導
Vi − 0R1 = 0 − VoR2i₁ = i₂
ViR1 = −VoR2
Vo = −R2R1·Vi兩邊同乘 −R₂
A = VoVi = −R2R1

例：R1 = 1 kΩ、R2 = 10 kΩ → A = −10 kΩ / 1 kΩ = −10。Vi = 0.1 V → Vo = −10 × 0.1 V = −1 V。
輸入阻抗 = R1：− 端是 0 V，從 Vi 看進去只看到 R1 接到「地」。這是它跟正相放大器最大的差別。

筆記勘誤（p.35）
  • 推導第一行右邊那項，筆記看起來寫成 (0 − Vi)/R2。R2 右邊接的是輸出，應該是 (0 − Vo)/R2。如果你原本寫的是 Vo 只是字跡像 Vi，就沒問題。
§2

正相放大器

Non-inverting amplifier
作用
放大小訊號，輸出和輸入同相，增益一定 ≥ 1。輸入阻抗 ∞，不會從訊號源拉電流。
原理
訊號直接進 + 端，虛短路把 − 端也拉到 Vi；R1、R2 其實是一個分壓器。

電路怎麼 work

  1. Vi 直接接 + 端 → v+ = Vi。
  2. 虛短路 → v− = Vi。
  3. R1 一端接地（0 V）、一端是 Vi → 電流 (0 − Vi)/R1（從地流向節點的方向寫，所以是負值）。
  4. 虛斷路 → 流過 R1 和 R2 的是同一個電流：(Vi − Vo)/R2。
推導（你的筆記寫到第一行，這裡補完）
0 − ViR1 = Vi − VoR2
−Vi·R2 = (Vi − Vo)·R1兩邊同乘 R₁R₂
−ViR2 = ViR1 − VoR1
VoR1 = ViR1 + ViR2移項
VoVi = R1 + R2R1
A = 1 + R2R1

另一種想法（分壓）：OP 不吃電流，所以 R2、R1 是串聯分壓：v− = Vo·R1/(R1 + R2)，再令它等於 Vi，一樣得到 Vo/Vi = (R1 + R2)/R1。
例：R1 = 1 kΩ、R2 = 9 kΩ → A = 1 + 9 kΩ / 1 kΩ = 1 + 9 = 10。
白板寫法：老師把回授電阻叫 Rf：Vo = (1 + Rf/R1)Vi，Rf 跟這裡的 R2 是同一顆。這個電路也是下一節減法器裡「V2 那一半」的基礎。

筆記勘誤（p.35 下半）
  • 電路圖上接地的電阻標成 R3，但公式 A = 1 + R2/R1 用的是 R1。請統一改成 R1，不然考試時會對不起來。
  • 推導只寫到 (0 − Vi)/R1 = (Vi − Vo)/R2，後面的移項請照上面補齊。
§3

電壓隨耦器

Voltage buffer / voltage follower
作用
不放大（Av = 1），用來「隔離」。前面看到輸入阻抗 ∞，不拉電流；後面看到輸出阻抗 0，接什麼負載 Vo 都不變。所以能推更多負載（fan-out ↑），沒有負載效應。
原理
輸出整條接回 − 端（100% 負回授），虛短路直接讓 Vo = Vi。

電路怎麼 work

  1. 輸出用導線直接接回 − 端 → v− = Vo。
  2. 虛斷路：+ 端不吃電流 → Rs 上電流 I = 0 → 壓降 I·Rs = 0·Rs = 0（筆記說的「不用付過路費」）→ v+ = Vi。
  3. 虛短路：v− = v+ → Vo = Vi。
  4. Ro = 0：OP 輸出像理想電壓源，接上 RL 後 Vo 還是 Vi（所以「V 不受 RL 影響」）。
推導
v+ = Vi − I·Rs = Vi − 0·Rs = Vi
Vo = v− = v+ = Vi
Av = VoVi = 1也可看成正相放大器 R₂ = 0、R₁ = ∞：1 + 0/∞ = 1

為什麼需要它：沒加 buffer vs 加了 buffer

「V 不受 RL 影響」是 buffer 的好處。老師為了說明這個好處，先畫了沒有 buffer 的情況給你看（下面第一張，筆記裡叫「左圖」）：這時候 Vo 會被 RL 拉低。加上 buffer（第二張，「右圖」）之後就不會了。所以下面的「分壓」講的是左圖、沒加 buffer 的壞處，不是 buffer 本身。

左圖（沒加 buffer）① 還沒接 RL
沒有電流 ⇒ Rs 沒有壓降 ⇒ Vo = Vi
左圖（沒加 buffer）② 接上 RL：分壓
Vo = Vi·RLRs + RL < Vi ⇒ Vo ↓這就是負載效應
例：Rs = RL = 1 kΩ ⇒ Vo = Vi × 1 kΩ1 kΩ + 1 kΩ = Vi × 12
右圖（加了 buffer）③ 接上 RL
i = 0 ⇒ v+ = Vi ⇒ 虛短路 v− = Vi ⇒ Vo = ViRL 沒出現在式子裡
同樣 Rs = RL = 1 kΩ：Vo = Vi（左圖只剩 Vi × 1/2）

筆記寫的「fan out ↑」是什麼意思：一個訊號源要同時推 100 個電路，這 100 個輸入電阻是並聯，總負載變得很小。假設每個電路輸入電阻 10 kΩ、Rs = 1 kΩ。
沒加 buffer（像左圖）：
RL = 10 kΩ / 100 = 100 Ω
Vo = Vi × 100 Ω / (1000 Ω + 100 Ω) = Vi × 100/1100 ≈ 0.091 Vi，只剩不到一成，後面的電路都收不到正確的電壓。
加了 buffer（像右圖）：訊號源只看到 OP 的 + 端（Ri = ∞，不用出電流，Vi 完整保留），100 個電路改由 OP 輸出（Ro = 0）來推，每個都拿到 Vi。

筆記勘誤（p.37）
  • 筆記寫「過路費 I·Rs = 0·Rs，Rs = 0」。Rs 本身不是 0，是 Rs 上的壓降為 0：VRs = I·Rs = 0·Rs = 0。
  • 對照新的白板照片：老師寫的是「I·Rs = 0·Rs」，下一行「= 0」，再下面那個「Rs」其實是電阻的標籤。抄的時候兩個黏在一起，就變成「Rs = 0」了。
§4

反相加法器

Inverting summing amplifier
作用
把多個輸入電壓「加權相加」再反相輸出，例如混音器。R1 = R2 = Rf 時就是 Vo = −(V1 + V2)。
原理
− 端是虛接地 0 V，所以每個輸入的電流各算各的、互不干擾，在節點匯合後全部流過 Rf。

電路怎麼 work

  1. + 端接地 → 虛短路 → − 端 = 0 V。
  2. R1 兩端：V1 和 0 V → i1 = V1/R1；R2 兩端：V2 和 0 V → i2 = V2/R2。因為節點固定在 0 V，V2 改變不會影響 i1。
  3. 虛斷路 → i1 + i2 全部流過 Rf。
  4. Rf 左邊 0 V、右邊 Vo → Vo = 0 − (i1 + i2)·Rf。
方法一：KCL
V1 − 0R1 + V2 − 0R2 = 0 − VoRf
Vo = −Rf(V1R1 + V2R2)
Vo = −(RfR1V1 + RfR2V2)
方法二：重疊定理（筆記的方法）
只留 V₁（V₂ 關掉＝短路接地）：
Vo1 = −RfR1V1
只留 V₂（V₁ 短路接地）：
Vo2 = −RfR2V2
Vo = Vo1 + Vo2

為什麼「V₂ 關掉」不會影響 V₁ 的那一半：V₂ 短路接地後，R2 一端是 0 V（地）、另一端也是 0 V（虛接地），兩端沒電壓差 → 沒電流 → 就像不存在，電路變回單純的反相放大器。
補充：重疊定理裡，電壓源關掉 = 短路，電流源關掉 = 開路。
白板寫法：Vo = V1·(−Rf/R1) + V2·(−Rf/R2) = −(V1·係 + V2·係)，「係」就是係數 Rf/R1、Rf/R2。

筆記勘誤（p.38）
  • 對照白板「△ 加法器」那張：匯合線和 − 端之間寫的是「0V」（標示虛接地），不是電阻。筆記很可能把這個手寫的「0V」抄成了一顆電阻。
  • 電路圖上 V1-R1、V2-R2 匯合之後，又多串了一顆電阻才接到 − 端。標準加法器沒有這顆，R1、R2 要直接接到 − 端節點。多串一顆的話，匯合點就不是 0 V，V1、V2 的電流會互相影響，Vo = −(Rf/R1·V1 + Rf/R2·V2) 就不成立了。

減法器（正反相加法器）

Difference amplifier / subtractor
作用
輸出跟兩個輸入的「差」成正比：Vo ∝ (V2 − V1)。白板標題「正相加法器」上面補了一個「反」：一個訊號走反相端（帶負號）、一個走正相端（帶正號），加起來就是減法。
原理
重疊定理：V1 單獨看是反相放大器，V2 單獨看是「先分壓、再正相放大」，兩個結果相加。

電路怎麼 work

  1. 只留 V1（V2 短路接地）：+ 端經 R2、R3 接地 → v+ = 0 → 變成反相放大器 → Vo1 = −(Rf/R1)V1。
  2. 只留 V2（V1 短路接地）：虛斷路，+ 端不吃電流，所以 R2、R3 是單純分壓 → v+ = V2·R3/(R2 + R3)。
  3. 這時 R1 從 − 端接地、Rf 接回輸出 → 變成正相放大器，把 v+ 放大 (1 + Rf/R1) 倍。
  4. 兩者相加：Vo = Vo1 + Vo2。
推導
Vo = −RfR1V1 + (1 + RfR1)·R3R2 + R3·V2
白板條件：RfR1 = 1（Rf = R1），R3R2 + R3 = 12（R2 = R3）
Vo = −1·V1 + (1 + 1)·12·V2
Vo = −V1 + 2·12·V2 = −V1 + V2
Vo = V2 − V1
一般條件（考試可能問）
設 RfR1 = R3R2 = k，則 R3 = kR2
V₂ 的係數 = (1 + k)·kR2R2 + kR2 = (1 + k)·k1 + k = k
Vo = k(V2 − V1) = RfR1(V2 − V1)
筆記勘誤（p.39）＋白板「V₂ − V₁ ⇒ 怎麼做？」
  • 你筆記的圖是 V2 直接接 + 端（沒有 R2、R3）。這樣算出來是 Vo = −(Rf/R1)V1 + (1 + Rf/R1)V2，就是白板右邊寫的那條。取 Rf = R1：Vo = −V1 + (1 + 1)V2 = −V1 + 2V2，不是 V2 − V1。
  • 白板問號的答案：在 + 端加 R2、R3 分壓，把 V2 先砍一半（× 1/2），再被放大 2 倍，係數就回到 1，得到 V2 − V1。
  • 筆記圖上 − 端那條輸入沒有標 V1 和 R1、回授電阻沒標 Rf，建議補上。
§6 · 白板 △

負阻抗轉換器／定電流源

Negative impedance converter · Howland current source
作用
① 從 + 端往 OP 那一側看進去，整塊電路等效成一顆 −R 的電阻（負阻抗，電容、電感也能做成負的）。② 這顆 −R 跟輸入的 R 抵銷，流過負載的電流固定 = Vi/R，與 RL 無關 → 定電流源。白板把 RL 畫成可變電阻（有箭頭的那顆），旁邊寫「阻值…不重要」，意思是 RL 怎麼調，電流都一樣。白板標題下還畫了電容和電感符號：同樣的接法把 R 換成 C 或 L，就能做出負電容、負電感。
原理
r1、r2 分壓決定 − 端電壓，虛短路把 + 端也鎖在同一個電壓，再對 + 端寫 KCL。

電路怎麼 work

  1. 這個電路同時有負回授（經 r2 回 − 端）和正回授（經 R 回 + 端）。負回授比例 = r1/(r1+r2) = 1/2，正回授分到的比例一定小於 1/2（因為 + 端還並著 RL），負回授比較強，所以虛短路仍可用。
  2. 令 r1 = r2 = r。虛斷路 → r1、r2 串聯分壓 → − 端電壓 Vx = Vo/2。
  3. 虛短路 → + 端（也就是 RL 上端）也是 Vx = Vo/2，換句話說 Vo = 2Vx。
  4. ① 流過輸入 R：(Vi − Vx)/R；② 流過回授 R（從 + 端流向 Vo）：(Vx − Vo)/R。
  5. + 端 KCL（OP 不吃電流）：流進 = ①，流出 = IL + ② → IL = ① − ②。
推導：IL 與 RL 無關
Vx = Vo·r1r1 + r2 = Vo·rr + r = Vo2
① = Vi − VxR = Vi − Vo/2R = 2Vi − Vo2R分子分母同乘 2
② = Vx − VoR = Vo/2 − VoR = −Vo/2R = −Vo2R
IL = ① − ② = 2Vi − Vo2R − (−Vo2R) = 2Vi − Vo + Vo2R = 2Vi2R
IL = ViR式子裡沒有 RL → 與 RL 無關
推導：看進去是 −R（白板紅字）
在 + 端把 RL 和輸入 R 剪開，只看「OP + 回授 R」這一側，外加測試電壓 Vx，流進去的電流就是 ②：
Ri = Vx② = Vo/2−Vo/(2R) = Vo2·2R−Vo
Ri = −R電壓為正，電流卻是「流出來」的 → 負電阻
一般式（r₁ ≠ r₂）：Vo = Vx(1 + r2r1) ⇒ Ri = −R·r1r2
白板例子：7 kΩ → −1 kΩ（r₁、r₂ 的值是我推的）
R = 7 kΩ，要 Ri = −1 kΩ
−7 kΩ·r1r2 = −1 kΩ ⇒ r1r2 = 1 kΩ7 kΩ = 17
接法一：r1 = 1 kΩ、r2 = 7 kΩ
驗算：Vo = Vx(1 + 7 kΩ1 kΩ) = Vx(1 + 7) = 8Vx
② = Vx − 8Vx7 kΩ = −7Vx7 kΩ = −Vx1 kΩ
Ri = Vx② = Vx ÷ −Vx1 kΩ = −1 kΩ ✓
接法二（如果白板 r₂ 上方的「1k」是 r₂）：r2 = 1 kΩ ⇒ r1 = 1 kΩ7 ≈ 142.9 Ω

Norton 等效：為什麼電流固定

1Req = 1R + 1−R = 0 ⇒ Req = ∞（開路）白板寫法：R·(−R)/(R + (−R)) = −R²/0 → ∞
電流源 Vi/R 唯一的出路就是 RL ⇒ IL = Vi/R（固定）

實際限制：Vx = IL·RL，而 Vo = 2Vx = 2·IL·RL。Vo 不能超過飽和電壓，所以 RL 不能無限大：2·(Vi/R)·RL ≤ Vsat → RL ≤ Vsat·R/(2Vi)。
例：Vsat = 3 V、Vi = 1 V、R = 1 kΩ → IL = 1 V / 1 kΩ = 1 mA；RL ≤ 3 × 1000 / (2 × 1) = 1500 Ω。

要注意的地方
  • 白板標題「電阻 7k → −1k」：數字就是 7k 和 −1k。上面的推導是 r1 = r2 的特例（R → −R）；7k 變 −1k 要用「一般式」，r1/r2 = 1/7（見上面的例子）。白板上 r2 正上方的「1k」是不是在標 r2，我不確定，所以兩種接法都列了。
  • R ∥ (−R) 的分母是 0，嚴格來說不是「除出 ∞」，用電導相加 1/R + 1/(−R) = 0 → 開路，寫起來比較不會被扣分。
§7 · 白板 △

積分器

Integrator
作用
輸出跟輸入對時間的積分成正比（Vi 曲線下的面積，就是白板右邊那張畫斜線的圖）。方波進去 → 三角波出來。
原理
R 把電壓變成電流 Vi/R，這個電流全部拿去給 C 充電；電容電壓 = 電流的累積。

電路怎麼 work

  1. + 端接地 → 虛短路 → v− = 0。
  2. R 兩端：Vi 和 0 V → Ic(t) = (Vi − 0)/R（白板藍字）。
  3. 虛斷路 → Ic 全部流進電容 C 充電。
  4. 電容公式 dVc/dt = i(t)/C，兩邊積分 → Vc(t) = (1/C)∫Ic(t)dt。
  5. 電容左邊 0 V、右邊 Vo：Vc = 0 − Vo → Vo = 0 − Vc(t)。
推導
Vo = 0 − Vc(t)
= −∫Ic(t)Cdt
= −1C∫Ic(t)dtC 是常數，提出來
= −1C∫ViRdt代入 Ic = Vi/R
Vo = −1RC∫Vi dt

例：Vi = 1 V（常數）、R = 10 kΩ、C = 1 μF → RC = 10 × 10³ Ω × 1 × 10⁻⁶ F = 10⁻² s = 0.01 s。Vo = −(1/0.01)·1·t = −100t（V）。t = 30 ms 時 Vo = −100 × 0.03 = −3 V，已經飽和。
實際電路：C 旁邊通常會並一顆大電阻，否則輸入一點點直流偏移也會被一直積分，最後飽和。

抄寫注意
  • 白板最後一行「= 1/C ∫ Ic(t) dt」照片裡負號不太明顯，抄的時候記得是 −(1/C)∫Ic(t)dt，負號來自 Vo = 0 − Vc。
§8 · 白板

微分器

Differentiator
作用
輸出跟輸入的「變化率」成正比。三角波進去 → 方波出來。積分器把 R、C 位置對調就是微分器。
原理
電容只在電壓變化時有電流（i = C·dV/dt）；這個電流全部流過 R，在 R 上產生電壓。

電路怎麼 work

  1. 虛短路 → v− = 0。
  2. 電容兩端：左邊 Vi、右邊 0 V → Vc(t) = Vi − 0 = Vi。
  3. 電容公式 dVc/dt = ic(t)/C → ic(t) = C·dVi/dt。
  4. 虛斷路 → ic 全部流過 R。
  5. R 左邊 0 V、右邊 Vo → Vo = 0 − ic(t)·R（白板黑字）。
推導（白板寫到 Vo = 0 − ic(t)·R，這裡補完）
dVc(t)dt = ic(t)C ⇒ ic(t) = CdVidtVc = Vi
Vo = 0 − ic(t)·R = −R·CdVidt
Vo = −RCdVidt

例：Vi 以 1 V/ms = 1000 V/s 上升、R = 1 kΩ、C = 1 μF → RC = 1 × 10³ Ω × 1 × 10⁻⁶ F = 10⁻³ s。Vo = −10⁻³ s × 1000 V/s = −1 V。
實際電路：雜訊變化很快（dV/dt 大），微分器會把雜訊放大，所以實際上會在 C 前面串一顆小電阻。
口訣：積分器「R 在前、C 在回授」；微分器「C 在前、R 在回授」。

§9 · 白板「7 指數放大」

指數放大器

Exponential (anti-log) amplifier
作用
輸出跟 eVi 成正比（白板紅字：Vo = eVi × 係數）。
原理
二極體的電流跟電壓是指數關係；虛接地讓二極體電壓剛好 = Vi，電流再經 R 變回電壓。

電路怎麼 work

  1. 虛短路 → v− = 0（白板上 − 端旁邊寫的「0V」）。
  2. 二極體兩端電壓 VD = Vi − 0 = Vi。
  3. 二極體方程式 ID = Is(eVD/nVT − 1)。順偏時 e 的那項遠大於 1，「−1」可以忽略。
  4. 虛斷路 → ID 全部流過 R。
  5. R 左邊 0 V、右邊 Vo → Vo = 0 − ID·R。
推導
ID = Is(e(Vi − 0)/nVT − 1) ≈ Is·eVi/nVT忽略 −1
Vo = 0 − ID·R
Vo = −Is·R·eVi/nVT−IsR 是係數，nVT 是常數
筆記勘誤／補充
  • 這個公式只在 Vi > 0 且 Vi ≫ nVT（二極體順偏）時成立。室溫 VT = kT/q ≈ 26 mV。Vi < 0 時二極體逆偏，ID ≈ −Is（非常小），Vo ≈ +IsR ≈ 0。
  • 白板把 nVT 標成「常數」：只在溫度固定時成立。VT = kT/q 和 Is 都會隨溫度改變，所以實際的指數放大器對溫度很敏感。
  • 白板第一條式子寫 Vi − 0 在指數上，意思是 VD = Vi − v− = Vi − 0，沒有寫錯。
考前檢查

勘誤總整理

  1. p.34 理想 OP「Vo still = v+ − v−」漏了 Av，應為 Vo = Av(v+ − v−)。

  3. p.34 理想 OP「負回授限制了 Av」：被限制的是閉迴路增益，OP 本身的開迴路 Av 仍是 ∞。
  4. p.34 理想 OP漏寫虛斷路（i+ = i− = 0）和 Ro = 0。
  5. p.35 反相放大器推導右邊分子應為 0 − Vo（若筆記寫成 0 − Vi 要改）。
  6. p.35 正相放大器圖上電阻標 R3、公式用 R1，要統一；推導未完成。
